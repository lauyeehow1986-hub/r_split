# sideview v0.2.0 Implementation Plan

> **For Claude / Antigravity:** REQUIRED SUB-SKILL: Use superpowers:executing-plans or superpowers:subagent-driven-development to implement this plan task-by-task.

**Goal:** Implement the 5 validated v0.2.0 milestone pillars: big data scalability & CRAN readiness, visual wrangling & profiling, canvas state persistence, intelligent copilot auto-mapping, and automated computer use GUI verification.

**Architecture:** Extend the normalized S3 data model and bi-directional Shiny WebSocket protocol with lazy data chunking, virtualized client-side DOM scrolling, multi-key join generation, state serialization (`.json`/`.rds`), heuristic foreign key detection, and automated browser testing via `shinytest2` and multimodal computer use recipes. External dependencies (`arrow`, `duckdb`, `ggplot2`, `shinytest2`) reside in `Suggests:` to ensure zero mandatory compilation overhead on CRAN.

**Tech Stack:** R (>= 4.0.0), Shiny, htmltools, htmlwidgets, dplyr, tidyr, forcats, httr2, jsonlite, rstudioapi; `Suggests:` arrow, duckdb, ggplot2, testthat (>= 3.0.0), shinytest2.
