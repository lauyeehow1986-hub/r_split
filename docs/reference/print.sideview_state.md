# Print Method for Sideview State Objects

Displays a concise summary of the canvas state including version, card
count, and active connections.

## Usage

``` r
# S3 method for class 'sideview_state'
print(x, ...)
```

## Arguments

- x:

  A `sideview_state` object.

- ...:

  Unused additional arguments.

## Value

Invisibly returns `x`.
